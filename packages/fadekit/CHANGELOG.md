# fadekit

## 0.3.0

### Minor Changes

- Composable, order-independent utilities built on `--fade-color` / `--fade-angle` / `--fade-stops` (no more `!important`; works with variants).
  - Colors: opacity modifiers (`fade-from-black/50`), arbitrary values and CSS variables (`fade-from-(--brand)`), `current`.
  - Direction: any angle (`fade-to-45`, `fade-to-[200deg]`).
  - Curves: `fade-{easing}` and `fade-{easing}/{steps}`, new `scrim`, `ease-in`/`ease-out`/`ease-in-out` shorthands, sine/quint/expo/circ families and `fade-[cubic-bezier(…)]`.
  - Stops are computed from the easing (the hardcoded table was `ease-out-cubic` rounded, with malformed data for 18–24 steps), placed where the curve bends, and the count is automatic unless set.
  - Fixes `fade-to-{color}` being flipped by `fade-{steps}`, and nested elements inheriting their parent's direction.
  - Legacy classes (`fade-{dir}`, `fade-{easing}-{steps}`, `fade-ease-*`) keep working.
